Real-Time Motion Detection:
This project implements a real-time motion detection system using Python, OpenCV, and Flask. The system captures video from a camera, processes frames to detect motion, and highlights the moving objects. Flask is used to create a web interface for live video streaming and remote monitoring. The project also utilizes HTML, CSS, and JavaScript for the front-end, providing a responsive and interactive UI.

Technologies: Python, OpenCV, Flask, HTML, CSS, JavaScript.
